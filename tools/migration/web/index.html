METADATA ONLY

A local workbench for investigating stock Awair firmware. This is not a flasher. Files stay in your browser, and Bluetooth discovery does not read or write characteristic values.

No verified stock-install path yet. Do not factory-reset a Glow C, Glow or V1 for discovery. A visible Bluetooth service, firmware hash or TLS connection does not prove that custom firmware can be installed.

01 / BLUETOOTH

Inventory accessible services

The browser can see only explicitly permitted services. For a fuller OS-exposed inventory, use the native collector in the repository.

02 / FIRMWARE

Inspect a local image

Compute SHA-256 and find known update/security markers and candidate vectors. No image is uploaded or sent to a device.

Raw firmware may contain private keys or credentials. The report contains marker offsets, not extracted strings.

03 / NETWORK EVIDENCE

Summarize a device capture

Select a TShark JSON export from your own network capture. The device IP scopes the analysis; it is omitted from the report. Only three known Awair hostnames are exported. Unknown hostnames are counted, not disclosed.
